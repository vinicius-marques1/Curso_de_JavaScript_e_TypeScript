# Curso de JavaScript e TypeScript

Este repositório foi criado para armazenar as aulas, exercícios, projetos e anotações do curso de JavaScript e TypeScript da Udemy, com foco em desenvolvimento web moderno.

Curso: https://www.udemy.com/course/curso-de-javascript-moderno-do-basico-ao-avancado/?couponCode=MT260727G1

O objetivo principal é registrar o aprendizado em uma estrutura organizada, permitindo consultar os conteúdos estudados ao longo do curso e acompanhar a evolução das habilidades em front-end, back-end e desenvolvimento full stack.

## Sobre o projeto

Este é um projeto de estudo, voltado para prática e documentação do aprendizado em:

- JavaScript básico, intermediário e avançado
- Programação funcional
- Programação orientada a objetos
- Desenvolvimento front-end com HTML5, CSS3 e JavaScript
- Desenvolvimento back-end com Node.js e Express
- Criação de APIs REST
- Persistência com MongoDB, MySQL e MariaDB
- Segurança de servidor com SSH e TLS/HTTPS
- Autenticação com JWT
- TypeScript
- Webpack e Babel
- Uso de Mongoose com MongoDB
- Sequelize para integração com banco relacional

## Conteúdo aprendido

### JavaScript

- Sintaxe básica e conceitos fundamentais
- Variáveis, estruturas de controle e loops
- Funções, arrays, objetos e protótipos
- Programação orientada a objetos com classes e instâncias
- Manipulação de eventos e DOM
- JavaScript assíncrono: callbacks, promises e async/await
- Modularização com ES6 Modules
- Ferramentas de build e transpilation com Webpack e Babel

### Front-end

- HTML5 e CSS3
- Estruturação de páginas e componentes básicos
- Estilização e responsividade
- Integração com JavaScript moderno
- Configuração de ambientes com Webpack e Babel
- Desenvolvimento de interfaces com foco em organização e reutilização de código

### Back-end

- Node.js
- Express
- Criação de rotas e controllers
- Middlewares e estruturação de aplicações
- Sessões, mensagens flash e autenticação
- Criação de APIs REST
- Autenticação com JWT
- Integração com bancos de dados

### Bancos de dados

- MongoDB com Mongoose
- MySQL/MariaDB com Sequelize
- Modelagem básica de dados
- Operações de CRUD

### Segurança

- Configurações básicas de segurança para servidores
- Uso de SSH
- Configurações de TLS/HTTPS
- Proteção de rotas e autenticação de usuários

### TypeScript

- Introdução à tipagem estática
- Interfaces, tipos, classes e generics
- Organização de código mais segura e escalável
- Integração com projetos front-end e back-end

## Estrutura do repositório

O repositório está organizado por módulos, seguindo a progressão do curso:

- modulo2_javaScript_basico: fundamentos do JavaScript
- modulo3_logica_de_programacao: lógica e estruturas de controle
- modulo4_funcoes_no_js: funções e reutilização de código
- modulo5_arrays: manipulação de arrays
- modulo6_objetos_e_prototypes: objetos e protótipos
- modulo7_classes_js: classes e programação orientada a objetos
- modulo8_javascript_assincrono: programação assíncrona
- modulo9_javaScript_Tooling_e_ES6_Modules: ferramentas e módulos
- modulo10_node: estudos com Node.js
- modulo11_API_REST: construção de API REST com Express e Sequelize
- modulo12_TypeScript: introdução ao TypeScript e configuração de build
- modelo e modelo-webpack: projetos de exemplo e exercícios práticos
